# OCP Hackathon 2026 — Monorepo

This repository contains two projects:

- `backend` — Express + Prisma API
- `frontend` — Vite + React app (from branch `frontend-ved`)

Quick start

1. Start backend (API):

```bash
cd backend
npm run dev
```

2. Start frontend (dev server):

```bash
cd frontend
npm run dev
```

Notes

- Frontend was integrated from the `frontend-ved` branch and placed in the `frontend` folder.
- Backend is located in the `backend` folder and uses Prisma for database migrations.
